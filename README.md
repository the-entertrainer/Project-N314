# Nifty Intel (Project N314)

**AI-Powered Real-time Stock Dashboard for Indian Markets**

Modern rewrite from scratch using Next.js 16 (App Router), Tailwind CSS, TypeScript, Recharts, TanStack Query, Zustand, and Gemini AI.

## Features
- Live Market Overview (Nifty, Bank Nifty etc.)
- Advanced Stock Screener
- Intelligent AI Advisor
- Portfolio & Watchlist Tracker
- Beautiful Dark UI with smooth interactions

## Tech Stack
- Next.js 16 + React 19
- TypeScript
- Tailwind CSS + shadcn/ui style
- Recharts for visualizations
- TanStack Query for data fetching
- Zustand for state

## Getting Started

```bash
npm install
npm run dev
```
